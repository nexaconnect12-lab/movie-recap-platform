# Phase 2 selected-video scene detection

The separately proposed PySceneDetect slice was confirmed on 2026-10-13 (Asia/Singapore). It adds real selected-stream decode and scene boundaries only. Sources, rights, original hosts and application database remain preserved; testing uses isolated binaries, generated media copies and disposable PostgreSQL databases.

VideoProcessing Domain defines immutable analysis binding and ordered contiguous end-exclusive ranges without framework dependencies. Application owns request/replay/history/execution ports. Media Application exposes selected-video snapshots and source-verification/transaction contracts; Media Infrastructure owns all reads/locks of Media tables. Video storage owns `video.SceneAnalyses` and `video.MovieScenes`, and uses Jobs `IJobTransaction` for atomic creation and fenced completion/audit. No cross-module FK/navigation or Video query of Media tables is added. Hosts compose adapters and dispatch `video.scene-analysis`; generic job creation remains foundation-only.

The Python subprocess runs real PySceneDetect ContentDetector with suppress filtering, using PyAV to decode exactly the selected global video stream. Boundaries map decoded ordinals to actual presentation timestamps. First PTS is retained as offset and normalized to zero; the final frame's real duration or real selected-stream end supplies exclusive end time. Missing/nonmonotonic timing fails rather than guessing. Single scenes, nonprimary streams, VFR and offset sources are exercised with owned fixtures.

Shell-free execution uses JSON stdin/bounded JSON-line stdout, bounded discarded stderr, timeout/process-tree cancellation, decoder/OpenCV single-thread settings and frame/pixel/time/range caps. Timestamp storage is bounded by decoded-frame limit. This is not a strict operating-system memory sandbox: codec allocation may occur before the decoded frame size can be checked. Trusted stable source roots and reference-only media remain assumptions. Original SHA-256/size are verified twice under a retained read-only source handle. Completion rechecks current selection under a shared row lock and matches an unexpired job lease, committing all ranges/analysis/job/audit together. Failure publishes no partial ranges. Historical successful results remain retrievable after selection changes; retry uses the original snapshot.

Configuration/endpoints: [scene API](../api/scene-analysis.md). Decision: [ADR 0008](../decisions/0008-selected-stream-scenes.md). Evidence: [verification](phase-2-scenes-verification.md). No audio/subtitle extraction, frame thumbnails, black-bar/overlay analysis, semantic analysis, AI/TTS, rendering, UI or publishing is delivered. Next proposed Phase 2 slice is source-preserving selected-audio extraction with an artifact lifecycle; it needs separate confirmation.
