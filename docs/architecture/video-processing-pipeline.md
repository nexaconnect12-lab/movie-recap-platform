# Video processing pipeline — import, selection, scenes, audio and frame artifacts implemented
Stable authorized input → hash/probe → stream selection/black-bar and overlay analysis → scene detection/thumbnails/audio → edit timeline → FFmpeg render → probe/validate final output. Preserve the original file. Do not process files still being copied. Python/PySceneDetect is a bounded subprocess adapter, not embedded domain logic.

Invoke tools without shell interpolation, constrain paths/resources, stream progress, terminate process trees on cancellation, retain stderr safely and record tool/version provenance. Removable selectable subtitles and authorized overlay edits are distinct from ownership-watermark concealment, which is prohibited.

Rendering uses configurable landscape 1920×1080 and vertical 1080×1920 profiles, narration/audio mix, aligned subtitles, cleanup and hardware encoding capability checks. Validate duration, streams and playability before promoting temporary files atomically. Phase 1 has no FFmpeg, probe, scene detection or render execution.

Phase 2 manual import now implements stable-file observation, SHA-256 deduplication and real FFprobe metadata/container/video-stream validation through Media Application ports. It accepts rights assertions for inspection while marking them Unreviewed. No stream extraction/selection workflow, black-bar/overlay analysis, scene detection, thumbnails, audio extraction or rendering is implemented. FFmpeg was used solely to generate owned synthetic test inputs. Production subprocess stderr is bounded and discarded rather than persisted because arbitrary media/tool diagnostics may contain sensitive metadata. See ADR 0005 and the manual-import API guide.

Optional worker folder monitoring now feeds a persistent discovery inbox. Versioned source/rights submission creates an import bound to that observed location/file revision, using the same real hash/probe pipeline. Changed sources require a new discovery submission; monitoring alone creates no jobs. See ADR 0006.

Full stream inspection and explicit video/audio/subtitle selection persist through Media. Cover art and incompatible/unknown track types cannot be chosen; source identity is hashed before versioned/audited selection writes. Legacy reinspection uses actual bounded FFprobe and a fenced job. See ADR 0007 and ../api/media-streams.md. Summary metadata remains the original first-video/first-audio summary; consumers use chosen indexes and inventory metadata.

The confirmed scene slice adds VideoProcessing-owned analysis/history/ranges and real ContentDetector processing. PyAV decodes the selected global video stream directly, retaining actual PTS-based end-exclusive ranges and first-frame offset, including VFR. No remux/extraction is performed. The read-only source is hashed before/after decode; completion rechecks selection and job lease and atomically saves all ranges/job/audit. Timeout/cancellation kills the Python process tree. Runtime/output/frame/pixel/duration/range caps bound execution; frame-cap progress is coarse. See ADR 0008 and ../api/scene-analysis.md. Thumbnails, audio/subtitle extraction, black-bar/overlay analysis and rendering remain unimplemented. Earlier paragraphs describe historical slices, not current scene capability.


Selected-audio extraction now executes real FFmpeg against Media's explicitly chosen global audio index. Original source is held read-only and hashed twice; bounded raw PCM becomes validated 16 kHz mono 16-bit WAV. Attempt files promote without overwrite under lease/selection fences; database reference/job/audit commit atomically, and only committed references can be downloaded. Crash/rollback orphans are reference-aware cleanup targets; completed artifacts/history remain. See ADR 0009 and ../api/audio-extraction.md. Earlier descriptions are historical. Thumbnail/subtitle/black-bar/overlay/semantic processing and rendering remain future.

Scene frame artifacts now execute real FFmpeg sequential chosen-stream decode without approximate seeks/FPS timing guesses. Quantile frame ordinals come from completed scenes; original integer PTS/timebase yields source seconds, and the analysis offset yields normalized seconds. Validate both mapping and scene membership. PNGs fit encoded frames at 320×180 without cropping (black padding/square pixels/no auto rotation), with full CRC/pixel/header/hash validation. Batch staging/promotion/reference-aware cleanup reuses audio's fencing pattern and shared path guard. See ADR 0010 and ../api/scene-frames.md. Earlier slice exclusions are historical; black-bar/overlay/semantic analysis, subtitles and recap rendering remain future.


Preparation is now reviewable through a combined current-choice scenes/audio/frame view. Ready metadata is distinct from real filesystem integrity: a worker job hashes/verifies original source and referenced WAV/PNGs, retains handles and atomically records its report/review version/audit with fenced job completion. A completed check may report passed=false. Operator approval repeats file checks and records a versioned decision; failed/current-changed checks cannot approve. Rejection can record incomplete input. Original files/rights stay unchanged and prior successful artifacts remain history. See ADR 0011 and ../api/preparation-review.md; no AI/transcription/render/publish is triggered by approval.
